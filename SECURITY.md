# Security policy

Created by Rosetta.

## Supported releases

Please use the latest public Windows release from [Releases](https://github.com/MagicJocey/petcompanion-releases/releases/latest). Security fixes are provided through new releases; older versions do not have a separate maintenance commitment.

Export a private backup before updating. Download installers only from the official PetCompanion release repository.

## Report a vulnerability privately

For suspected issues involving unauthorized access, exposure of notebook or save data, or unsafe update behavior, contact **Roses2403 on Discord** by private message. This is the maintainer's reporting contact, also listed in the Code of Conduct.

If GitHub shows a **Report a vulnerability** option in this repository's Security tab, you may use that private reporting form instead.

If neither route is available, open an issue that only asks for a private security contact. Do not include the vulnerability, reproduction details or affected personal data in that public issue.

A helpful private report includes:

- The affected app version and Windows version.
- A description of the issue and its possible impact.
- Minimal reproduction steps using made-up data.
- Whether the issue concerns installation, updates, saves, notebook content or another feature.

Do not attach real notebook entries, save files, backups, credentials or access tokens. Test only on your own device and data, or with the owner's permission. Do not access or expose another person's information to demonstrate an issue.

The maintainer will review reports as availability permits. There is no guaranteed response timeline or paid bounty program announced here.

## Ordinary bugs

Animation, layout and other non-security bugs belong in the [bug-report form](https://github.com/MagicJocey/petcompanion-releases/issues/new?template=01-bug-report.yml). Please keep security details out of public issues and discussions.
