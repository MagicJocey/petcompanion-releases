# Helping PetCompanion grow

Created by Rosetta.

Thank you for trying PetCompanion! Useful bug reports, accessibility feedback, pet ideas and small documentation improvements all help the project grow.

This repository hosts public Windows downloads, release notes and community feedback. The application source is maintained separately. You do not need to be a programmer to help.

## Before posting

- Read the [latest release notes](https://github.com/MagicJocey/petcompanion-releases/releases/latest) and search [existing issues](https://github.com/MagicJocey/petcompanion-releases/issues) for the same problem.
- If someone already reported it, add useful details to their issue instead of opening a duplicate.
- Use [Discussions](https://github.com/MagicJocey/petcompanion-releases/discussions) for questions, general feedback and sharing ideas that are still taking shape.
- Follow our [Code of Conduct](CODE_OF_CONDUCT.md).

## Reporting a bug

Choose **Bug report** on the [new issue page](https://github.com/MagicJocey/petcompanion-releases/issues/new/choose).

Please include the app version, Windows version, what you expected, what happened and steps we can follow to reproduce it. For pet artwork or animation problems, include the pet, evolution, appearance and action, and whether compact mode was on. For update problems, include the version you started with and the exact error message.

Screenshots are welcome when they help. Crop or cover personal details first.

## Suggesting a feature or pet

Choose **Feature or pet idea** and describe what you would like and how it would help. Ideas are welcome; submitting one does not guarantee that it will be added or set a release date.

Only attach artwork you created or have permission to share, and identify any attribution or permission requirements. Please mention AI assistance when relevant. Avoid sharing another creator's artwork without permission.

## Accessibility feedback

Choose **Accessibility feedback** for barriers involving keyboard use, screen readers, contrast, text size, motion or layout. Describe the task and the barrier; you do not need to disclose a diagnosis or other personal information. See [Accessibility](ACCESSIBILITY.md).

## Protect your notes and progress

Export a backup from **? / Welcome / Help** before troubleshooting updates. Keep that backup private.

Do not upload save files, notebook exports, backups, personal goals, passwords or access tokens to issues, discussions or pull requests. Share a short, made-up example instead. Check screenshots and error messages for private information before posting.

For a suspected security vulnerability, follow [SECURITY.md](SECURITY.md) rather than posting details publicly.

## Documentation pull requests

Small fixes to public documentation, links and templates are welcome. Explain what changed and why, check links and previews, and use the pull-request checklist.

Please discuss larger changes first. Do not upload application source, installers, generated build folders, dependencies or user data in a pull request. Official installers belong in Releases and are published by the maintainer.

Rosetta reviews contributions as time allows; there is no guaranteed response or release schedule.
