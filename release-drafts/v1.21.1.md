# PetCompanion v1.21.1 — Update connection

Created by Rosetta

- The installed Windows app checks GitHub Releases on startup.
- Open ? / Welcome / Help and choose Check for updates at any time.
- Available updates show their version and release notes. Choose whether to download; downloaded updates require approval before restarting and installing.
- Closing the app never silently installs a downloaded update. Offline checks leave your pets and goals alone.
- Regular updates keep the regular app and save identity. A validated pre-update save copy is created before installation.
- Master and Preview editions remain separate and update manually; they never install public regular releases.

Install this version manually once to enable checks for future releases. Export a backup, close the regular app and run PetCompanion-Setup-1.21.1-x64.exe in the same installation location. Electron is included. The current app version stays current until a newer release is published.

This is an unsigned Windows public testing build. Windows installation and an actual newer-version update still require PC validation. Automatic checks do not upload your pets, goals or backups. Artwork and app icon were created with AI assistance.
