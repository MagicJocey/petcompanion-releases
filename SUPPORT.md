# PetCompanion help

Created by Rosetta.

## Download or update

Get the Windows x64 installer from [the latest release](https://github.com/MagicJocey/petcompanion-releases/releases/latest). Electron is included; you do not need Node.js, npm or a command prompt.

Installed public versions from 1.21.1 onward check for updates on startup. You can also open **? / Welcome / Help → Check for updates**. Downloads and installation ask for approval; closing the app does not silently install an update.

Export a backup from Welcome / Help before updating. If installing manually, close PetCompanion and use the same installation location. Keep your backup private.

## Where to ask

- **Questions and general feedback:** [Discussions](https://github.com/MagicJocey/petcompanion-releases/discussions).
- **Crashes, update failures or pet/goal problems:** [Bug report](https://github.com/MagicJocey/petcompanion-releases/issues/new?template=01-bug-report.yml).
- **Feature or pet suggestions:** [Feature or pet idea](https://github.com/MagicJocey/petcompanion-releases/issues/new?template=02-feature-request.yml).
- **Accessibility barriers:** [Accessibility feedback](https://github.com/MagicJocey/petcompanion-releases/issues/new?template=03-accessibility.yml).
- **Suspected security problems:** [Security reporting](SECURITY.md).

Check existing issues first. Include your app version, Windows version and reproduction steps when reporting a problem. For graphics problems, name the pet, form, appearance, action and display mode.

Never post personal notebook entries, saves or backups publicly. Use made-up examples and crop screenshots. Support is community feedback for an independent project, with no guaranteed response time.
