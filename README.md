# PetCompanion

**Created by Rosetta**

A cozy desktop companion for little goals and a growing fantasy pet family.

## Downloads

Windows downloads will appear on this repository’s Releases page after the first build is verified. Electron is included; testers do not need Node.js or npm.

## What’s inside

- Ten animated fantasy pet families and discoverable evolution forms.
- A goal notebook with 10–100 XP rewards for a chosen pet.
- Pet-themed notes, nine achievements, and compact mode.
- A welcome screen, release notes, and local backup tools.

This public repository hosts downloads, release notes and tester feedback. Application development source is maintained separately in a private repository.

Export a backup from Welcome / Help before upgrading. Please do not attach saves or backups to public issues: they may contain private notes.

Early builds are unsigned. Automatic online updates are not connected yet. Pet artwork and the app icon were created with AI assistance.
