# PetCompanion

**Created by Rosetta**

A cozy Windows desktop companion for little goals and a growing fantasy pet family.

## Download the current public preview

[**PetCompanion v1.21.0 — Care, feeding & special hatches**](https://github.com/MagicJocey/petcompanion-releases/releases/tag/v1.21.0)

Download `PetCompanion-Setup-1.21.0-x64.exe` from the release’s Assets section. Electron is included: no separate Electron install, Node.js, npm or command prompt is needed.

Older public previews remain on the [Releases page](https://github.com/MagicJocey/petcompanion-releases/releases).

## What’s inside

- Ten animated fantasy pet families, with 35 discoverable collection forms.
- A goal notebook with 10–100 XP rewards for your chosen pet, pet-themed notes and nine achievements.
- Per-pet saved care bars, pet-specific foods, egg tending and feeding animations for all 25 hatched forms.
- Feed or tend below 50% care to refill and earn 10 XP. Care decreases over roughly 24 hours, including time away. Pets never die or lose levels from hunger.
- Unfinished goals assigned to a pet increase future care drain by 10% each, capped at 2×. Completing or deleting goals lowers future drain.
- Egg tending improves a one-time alternate-color hatch chance; special colors follow evolutions and coordinate habitats, goal cards and XP/care bars.
- Compact mode, a welcome screen, release notes, custom artwork and local backup tools.

## Upgrade safely

Export a backup from **? / Welcome / Help**, close the regular app, then run the new installer using the same installation location. Regular releases keep the app identity and save location so pets, goals and progress carry forward.

Master and Preview are separate testing editions. Installing a regular update does not replace those apps. Public downloads do not include Master inspection controls or automatically unlock pets/forms.

Automatic online update checking is not connected yet. Download and install updates manually for now.

## Feedback and privacy

Report bugs through [Issues](https://github.com/MagicJocey/petcompanion-releases/issues) with your Windows version and reproduction steps. Keep save files and backups out of public issues because they may contain personal notes.

This public repository hosts Windows downloads, release notes and tester feedback. Application source stays in a separate private repository. GitHub’s generated source ZIP/tar archives here contain this downloads repository, not the private application source.

These are early, unsigned public testing builds. Pet artwork and the app icon were created with AI assistance.
