# PetCompanion

**Created by Rosetta**

A cozy Windows desktop companion for little goals and a growing fantasy pet family.

## Download the current public preview

[**PetCompanion v1.22.0 — Flowerhood & Celestial Sonata**](https://github.com/MagicJocey/petcompanion-releases/releases/tag/v1.22.0)

Download `PetCompanion-Setup-1.22.0-x64.exe` from the release’s Assets section. Electron is included: no separate Electron install, Node.js, npm or command prompt is needed.

Already using 1.21.1? Open **? / Welcome / Help → Check for updates**. Available updates show their version and release notes, and ask before downloading and installing.

Older public previews remain on the [Releases page](https://github.com/MagicJocey/petcompanion-releases/releases).

## What’s inside

- Eleven animated fantasy pet families, with 42 discoverable collection forms.
- Flowerhood: 31 appearances and a growing family, from a duo at level 2 to a five-companion tower at level 20. Saved partners, corrected movement and shared berry-bowl meals follow every stage.
- Celestial Sonata at level 5, with Original, Dawncloud and Amber appearances, feeding animations and sleeping poses. Amber enjoys Sunstone nectar.
- A goal notebook with 10–100 XP rewards for your chosen pet, pet-themed notes and nine achievements.
- Per-pet saved care bars, pet-specific foods, egg tending and feeding animations.
- Feed or tend below 50% care to refill and earn 10 XP. Care decreases over roughly 24 hours, including time away. Pets never die or lose levels from hunger.
- Unfinished goals assigned to a pet increase future care drain by 10% each, capped at 2×. Completing or deleting goals lowers future drain.
- Special hatch colors follow evolutions and coordinate habitats, goal cards and XP/care bars.
- Compact mode, a welcome screen, release notes, custom artwork and local backup tools.

## Updating

Export a backup from **? / Welcome / Help** before updating. Use **Check for updates**, or close the app and run the installer manually in the same installation location. Regular releases keep the app identity and save location so pets, goals and progress carry forward. Closing the app never silently installs a downloaded update.

## Feedback and privacy

Report bugs through [Issues](https://github.com/MagicJocey/petcompanion-releases/issues) with your Windows version and reproduction steps. Keep save files and backups out of public issues because they may contain personal notes.

This public repository hosts Windows downloads, release notes and tester feedback. Application source stays in a separate private repository. GitHub’s generated source ZIP/tar archives here contain this downloads repository, not the application source.

These are early, unsigned public testing builds. Pet artwork and the app icon were created with AI assistance.
